# DerdiniS

Bu Expo projesi, dertlerinizi yazarak animasyonlu bir "başarıyla sikildi" mesajı
görmenizi sağlayan basit bir mobil uygulamadır.

## Projeyi Çalıştırma

1. Gerekli bağımlılıkları yükleyin:

   ```bash
   npm install
   ```

2. Expo geliştirme sunucusunu başlatın:

   ```bash
   npm start
   ```

3. Dilediğiniz platformda çalıştırın:

   - Android için: `npm run android`
   - iOS için: `npm run ios`
   - Web için: `npm run web`

## Özellikler

- Başlık, metin kutusu, reklam alanı ve eylem butonu içeren ana ekran.
- Butona basıldığında tüm ekranı kaplayan animasyonlu başarı bildirimi.
- Dokunarak kapanan başarı katmanı.
